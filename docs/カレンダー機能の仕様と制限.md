# カレンダー機能の仕様と制限

ホーム画面に追加した案件カレンダーの仕様と、現状の制限・今後できないことについてまとめます。

---

## 実装済みの仕様

### 表示内容

- **月ビュー**: 1か月単位でカレンダーを表示
- **表示対象**: `start_date`（着工日）または `due_date`（完了予定日）が設定されている案件のみ
- **イベント表示形式**: `案件番号 部門 顧客名`（例: K-001 工事 山田太郎）
- **日付の扱い**:
  - `start_date` と `due_date` の両方がある場合 → 着工日から完了予定日まで期間として表示
  - `start_date` のみ → その日付に表示
  - `due_date` のみ → その日付に表示
- **日本語表示**: 曜日・月・ボタン文言を日本語化

### 操作

- **案件クリック**: イベント（案件）をクリックすると、該当案件の見積ページ（`/projects/[id]/estimates`）へ遷移
- **月切り替え**: ツールバーの「前」「次」ボタンで月を切り替え
- **今日ボタン**: 「今日」ボタンで当月に戻る

### UI

- アプリのテーマカラー（オレンジ系）に合わせたスタイルを適用
- 今日の日付をハイライト
- カード風レイアウトで囲んで表示

## 制限事項・できないこと

### 1. 日付未設定の案件はカレンダーに表示されない

- **理由**: カレンダーは「日付」でソート・表示するため、`start_date` と `due_date` が両方 `null` の案件は表示できません
- **対応**: 案件登録時に着工日または完了予定日を入力してください。案件一覧ページでは日付未設定の案件も表示されます

### 2. 週ビュー・日ビューは非対応

- **理由**: 今回は月ビューのみ実装
- **対応**: 将来、`react-big-calendar` の `views` に `week` や `day` を追加すれば対応可能です

### 3. カレンダーから案件の新規登録はできない

- **理由**: カレンダーは閲覧・遷移専用で、新規登録フォームは持っていません
- **対応**: 案件の新規登録は「案件一覧」ページの「新規登録」から行ってください

### 4. 日付クリックで案件を追加する機能はなし

- **理由**: 未実装
- **対応**: 日付をクリックしても何も起こりません。イベント（案件）をクリックした場合のみ遷移します

### 5. ドラッグ＆ドロップで日付変更は不可

- **理由**: 未実装
- **対応**: 案件の日付を変更する場合は、案件一覧から該当案件を編集するか、将来の拡張で対応します

### 6. 担当者・ステータスでのフィルタはなし

- **理由**: 未実装
- **対応**: 全案件が表示されます。担当者やステータスで絞り込みたい場合は、案件一覧ページを利用してください

### 7. 表示月の範囲外のデータの扱い

- **理由**: 全案件をSupabaseから取得しているため、大量案件がある場合はパフォーマンスに影響する可能性があります
- **対応**: 現状は全件取得です。将来的に表示月に合わせた範囲クエリに変更する余地があります

### 8. モバイルでの操作性

- **理由**: `react-big-calendar` の月ビューは、スマホの小さい画面ではセルやイベントが小さくなることがあります
- **対応**: 横スクロールやピンチズームで全体を見ることができますが、タッチターゲットの最適化は未実施です

## 技術的な補足

### 使用ライブラリ

- `react-big-calendar`: カレンダーUI
- `date-fns`: 日付操作・日本語ロケール

### ファイル構成

- `app/components/ProjectCalendar.tsx`: カレンダーコンポーネント
- `app/(app)/page.tsx`: ホーム画面（カレンダーを埋め込み）
- `app/globals.css`: react-big-calendar のスタイルインポート・カスタムスタイル

### Supabase クエリ

- テーブル: `projects`
- 結合: `customers`（顧客名取得）
- 並び順: `start_date` 昇順（null は後ろ）
