# 全体操作手順

kannri-app の開発における操作の順番と、各作業が **Cursor 側** か **Supabase 側** かを一覧で示す。

---

## 操作の流れ（順番）

| 順番 | 作業内容 | 場所 | 詳細 |
|------|----------|------|------|
| 1 | Supabase プロジェクト作成 | Supabase | ダッシュボードで新規プロジェクト作成 |
| 2 | 環境変数・クライアント設定 | Cursor | `.env.local`、`lib/supabase/client.ts` |
| 3 | profiles テーブル作成 | Supabase | SQL Editor で実行 |
| 4 | テストユーザー作成 | Supabase | Authentication > Users |
| 5 | 管理者ロール設定（任意） | Supabase | SQL Editor で UPDATE |
| 6 | 認証 UI・ミドルウェア | Cursor | ログイン画面、 middleware |
| 7 | 顧客・企業テーブル作成 | Supabase | SQL Editor で customers |
| 8 | 顧客マスタ画面 | Cursor | 型定義、一覧、フォーム |
| 9 | 担当者テーブル作成 | Supabase | SQL Editor で staff |
| 10 | 担当者マスタ画面 | Cursor | 型定義、一覧、フォーム |
| 11 | 案件テーブル作成 | Supabase | SQL Editor で projects |
| 12 | 案件 CRUD 画面 | Cursor | 一覧、作成・編集 |
| 13 | 見積・請求書 | Cursor / Supabase | テーブル＋画面 |
| 14 | 実績・損益 | Cursor / Supabase | テーブル＋画面 |
| 15 | 集計・レポート | Cursor | 集計画面 |
| 16 | ロール・権限制御 | Cursor | profiles の role で出し分け |
