# 認証セットアップ手順

認証機能を動かすために必要な Supabase の操作は、**[docs/Supabase操作手順.md](Supabase操作手順.md)** に詳細をまとめています。

## 簡易手順

1. **profiles テーブルの作成**: SQL Editor で `supabase/migrations/20250209000000_create_profiles.sql` を実行
2. **テストユーザーの作成**: Authentication > Users > Add user > Create new user
3. **管理者設定（任意）**: SQL Editor で `UPDATE public.profiles SET role = 'admin' WHERE id = 'UUID'` を実行
4. **Email 認証**: デフォルトで有効。Authentication > Providers > Email で確認

詳細な手順・トラブルシューティングは [Supabase操作手順.md](Supabase操作手順.md) を参照してください。
